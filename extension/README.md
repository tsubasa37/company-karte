# 企業カルテ クリップ（Chrome拡張）

見ているページを**ボタンで選んで**企業カルテに送る拡張。ページの表示テキストを取得し、
アプリ側で AI が「どの企業のページか」を判定して取り込む。**勝手には送信しない**
（ポップアップを開いてボタンを押すまで、何もアプリに送られない）。

## ポップアップのボタン

| ボタン | 何をするか | 使う場面 |
|---|---|---|
| 🤖 自動判定で追加 | 種別（求人票/口コミ/ニュース等）もAIに任せる | 迷ったらこれ |
| 📄 求人票として追加 | 種別を求人票に固定して保存 | 求人詳細ページ |
| 💬 口コミとして追加 | 種別を口コミに固定して保存 → AIが1口コミずつに自動分割 | 口コミサイトのページ |
| 📰 ニュースとして追加 | 種別をニュースに固定して保存 | 記事・プレスリリース |
| 📋 一覧ページ → 企業だけ一括登録 | 企業名リストを抽出し、未登録の企業をまとめて登録（本文は保存しない） | お気に入り一覧・検索結果 |

企業ページ（1社）で自動判定したときに「複数企業が並ぶページ」と判定された場合は、
一括登録ボタンが青く強調され、そのまま一括登録に進める。

## 仕組み

```
ページを開いて拡張アイコンをクリック
 → ページの表示テキストを取得（SPAサイトは描画完了を最大8秒待つ）※この時点では送信しない
 → ボタンで追加方法を選ぶ
 → background.js が http://127.0.0.1:8123/api/clip (または /api/clip-list) に送信（X-Clip-Token 認証）
 → アプリのAIが企業名を判定（種別はボタン指定が優先）→ 企業を自動作成/名寄せ → ソース登録
 → 口コミは、さらにAIが「1口コミ=1件」に自動分割して保存（重複は除去）
```

自分のログイン済みブラウザで**自分が見ているページ**を保存するだけ。サイトへ余計なリクエストは
一切発生させない（bot による自動巡回・スクレイピングはしない）。送信先はローカルのアプリのみ。

## 重複防止

- **同じURL・同じ種別**を再取り込み → 上書き（重複ソースは増えない）。本文が変わっていれば旧版は変更履歴に退避
- **同じ口コミ**が複数ページに載っていても、内容の正規化ハッシュで企業内1件に統合
- **一括登録**は登録済み企業（法人格・表記ゆれも名寄せ）をスキップ

## ファイル構成

| ファイル | 役割 | Git |
|---|---|---|
| `manifest.json` | 拡張の定義 | 管理する |
| `popup.html` / `popup.js` | ボタンUI（取得と送信の分離） | 管理する |
| `common.js` | 共通処理（種別の表示名・描画完了待ち） | 管理する |
| `background.js` | アプリへの送信（唯一の送信経路） | 管理する |
| `config.js` | **実トークン**（`config.example.js` からコピーして作成） | **管理外** |

## 導入手順

1. アプリを起動しておく（別ターミナル）:
   ```bash
   cd company-karte
   composer run dev   # serve + queue + vite が一括起動
   ```
2. `extension/config.example.js` を `extension/config.js` にコピーし、`TOKEN` に
   `company-karte/.env` の `CLIP_TOKEN` と同じ値を設定する（`.env` 側は任意のランダム文字列。
   例: `php -r "echo bin2hex(random_bytes(16));"` の出力）
3. Chrome で `chrome://extensions` を開く → 右上「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」→ この `extension` フォルダを選択
5. ツールバーの拡張アイコンをピン留めしておくと使いやすい

**更新時**（このフォルダの中身が変わったとき）は、削除・再導入は不要。
`chrome://extensions` で「企業カルテ クリップ」の 🔄（更新）ボタンを押すだけ。

## 注意

- ローカル専用。取り込んだ内容は手元のアプリに保存される。企業・種別の判定と口コミの分割のため、本文はアプリの設定画面で選んだ AI の実行先に送られる（README の「データの扱い」を参照）
- 判定・分割はアプリの「抽出・判定」の実行先で行う。codex（ChatGPTサブスク）ならAPI課金は¥0、APIを選んでいる場合は従量課金（設定 → AIエンジン）
- 種別や企業名の判定が外れた場合は、アプリの企業詳細画面で修正できる
- 画像主体で文字が取れないページは取り込めない（テキストが read できるページ向け）
