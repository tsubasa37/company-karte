求人票の「言い回し」を分析してください。3つのタスクがあります。

## タスク1: 危険フレーズ検出（rhetoric_flags）
次の辞書に該当する表現、および同種の含みを持つ言い回しを検出する。
| フレーズ例 | 疑うこと |
| アットホームな職場 / 家族のような | 公私の境界が曖昧・具体的魅力の不在 |
| 若手が活躍 / 平均年齢20代 | 中堅が辞めて残っていない可能性 |
| 幹部候補 / 裁量が大きい / 任せる | 教育体制なしの丸投げ |
| やる気次第 / 頑張り次第で昇給 | 昇給基準が不明瞭 |
| 未経験歓迎 × 高収入 | 歩合・離職前提の大量採用 |
| 固定残業◯h分を含む / みなし | 基本給の圧縮・残業常態化 |
| スピード感 / 変化を楽しめる方 | 計画性のなさ・恒常的な炎上 |
| 賞与は業績による（実績記載なし） | 賞与が出ていない可能性 |
各検出: phrase(検出した表現) / quote(原文引用) / concern(何を疑うべきか)

## タスク2: 具体性スコア（concreteness）
数字・固有名詞・実績の密度を level(low|mid|high) で採点し、reason を1行。

## タスク3: 給与記載の抽出（salary_breakdown）
**計算はしない。原文に書かれている数値をそのまま拾うだけ**（基本給・実質時給の計算は後段のプログラムが行う）。
- has_fixed_overtime: 固定残業代/みなし残業が含まれるか
- fixed_overtime_hours: 原文に書かれた固定残業の時間数（月あたりの時間。記載が無ければ null）
- fixed_overtime_amount_yen: 原文に書かれた固定残業代の金額（円。記載が無ければ null）
- monthly_salary_min_yen: 月給（月額）の下限（円。年収表記のみで月額の記載が無ければ null）
- monthly_salary_max_yen: 月給（月額）の上限（円。単一額なら下限と同じ値、月額の記載が無ければ null）
- note: 内訳未記載・年収のみ記載など、読み取れなかった点や注意点。固定残業45h以上なら要注意と明記
給与記載が無い場合は has_fixed_overtime=false、数値項目はすべて null、note に「給与記載なし」。

数値の書き方: 「月給25万円〜35万円」→ monthly_salary_min_yen=250000 / monthly_salary_max_yen=350000。
「固定残業手当45時間分（6万円）を含む」→ fixed_overtime_hours=45 / fixed_overtime_amount_yen=60000。
換算・推定・按分はしない。原文に無い数値は null にする。

断定語は使わない。検出が無ければ rhetoric_flags は空配列。
